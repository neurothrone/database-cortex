# Docker Compose

---

## Setup

Create a docker-compose.yml file in a directory <span style="color: lightblue;">*DIR_NAME*</span>.

Open a terminal in the directory that contains the file and run the command:

```bash
docker-compose up
```

**OBS!** Depending on the size of the image it can take a few minutes.

Possible causes of errors:
- Docker Desktop is not running.
- Specified port already in use.
